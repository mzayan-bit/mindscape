# MINDSCAPE 🧠

**Mood Board-Based Psychological Support System for Students**

A comprehensive mental health support platform that leverages artificial intelligence and community engagement to provide accessible mental health assistance to students through an AI-powered chatbot and moderated discussion forums.

## 🎯 Overview

MINDSCAPE addresses the critical need for accessible mental health support among students by combining:
- **AI-Powered Support**: Immediate responses through advanced NLP  
- **Community Engagement**: Peer support via moderated discussion forums  
- **Secure Environment**: Safe space for mental health discussions  
- **24/7 Availability**: Round-the-clock support when traditional resources aren't available  

## ✨ Features

### 🤖 AI Mental Health Chatbot

- **Immediate Response**: Real-time mental health query processing  
- **Advanced NLP**: Powered by Ollama's Qwen 0.6B model  
- **RAG Implementation**: Retrieval Augmented Generation for accurate responses  
- **Knowledge Base**: Curated from reliable mental health resources  

### 👥 Community Forums

- **Topic-Based Organization**: Structured discussion boards  
- **Threaded Comments**: Organized conversation flow  
- **Moderation System**: Content oversight and community safety  
- **User Reporting**: Community-driven content moderation  

### 🔐 User Management

- **Secure Authentication**: Protected user accounts  
- **Profile Management**: Customizable user profiles  
- **Role-Based Access**: Moderator permissions and controls  
- **Privacy Protection**: Secure communication channels  

## 🛠 Technology Stack

### Backend

- **Framework**: Flask (Python)  
- **Database**: PostgreSQL  
- **Vector Store**: FAISS for embedding storage  
- **AI Model**: Ollama Qwen 0.6B  
- **NLP Pipeline**: LangChain framework  

### Frontend

- **Interface**: Web-based responsive design  
- **Authentication**: Session-based security  
- **Real-time**: Chat interface with message history  

### AI & Machine Learning

- **Model**: Ollama Qwen 0.6B  
- **Technique**: RAG (Retrieval Augmented Generation)  
- **Vector Database**: FAISS  
- **Document Processing**: PDF and web resource integration
